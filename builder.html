Two routes. The URL one is recommended.

You opened the builder from a file on this PC, so the Local file route is shown first. The URL route works too.

Loaded the settings.js from this folder.

  1. In OBS, click + under Sources and choose Browser.

  2. Leave Local file unticked and paste the URL.

    This URL is over 8,000 characters, and GitHub Pages, which hosts the overlay, refuses a longer one: OBS would show “URI Too Long” in place of chat. A letter outside A–Z takes 6 to 9 of them (an emoji 12). Shorten Hide messages containing, Highlight words or the lists of users, or take the Local file route with settings.js, which has no such limit.

    URL

    This is a file:/// URL because the builder is running from disk. OBS accepts it in the URL box with Local file unticked, and each source can have its own.

  3. Set Width and Height to the preview size.

    Width450
    Height700

  4. Untick these two. Left on, they reconnect and wipe the chat on every scene switch.

    Shutdown source when not visible Refresh browser when scene becomes active leave both unticked

  5. Leave Custom CSS at its default and click OK.

To change it later, paste the URL into Edit an existing overlay, adjust, then replace the URL in OBS.

Local file mode can’t take URL parameters, so the settings go in a settings.js file next to overlay.html.

  1. Get the overlay files: on GitHub choose Code, then Download ZIP, and unzip it somewhere permanent.

  2. Save settings.js in the same folder as overlay.html.

  3. In OBS, add a Browser source, tick Local file and pick overlay.html.

  4. Set Width to 450 and Height to 700.

  5. Untick Shutdown source when not visible and Refresh browser when scene becomes active.

  6. Whenever you change settings.js, open the source’s properties and click Refresh cache of current page.

Every Local file source in that folder shares one settings.js. For different setups, use the URL route instead with the file:///…/overlay.html?… URL this builder makes when you open it from that folder: it lists every setting, so the shared settings.js can’t change it.

Settings are remembered in this browser.
